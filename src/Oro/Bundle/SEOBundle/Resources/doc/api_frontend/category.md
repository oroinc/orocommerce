# Oro\Bundle\CatalogBundle\Entity\Category

## FIELDS

### canonicalUrl

The absolute canonical URL of the category for the current localization.
In contrast to the **url** field, this URL contains the scheme and the host.

### metaTitle

The meta title used for SEO optimization.

### metaDescription

The meta description used for SEO optimization.

### metaKeywords

The meta keywords used for SEO optimization.
